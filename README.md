# com4008

Space Invaders game made in Python using Pygame for the COM4008 Programming Concepts module.

## Team

- Konstantin - aliens (3 types, move side to side, shoot randomly, speed up)
- Adrian - player (multiple bullets, collisions, lives and respawning)
- Kallen - barriers (get damaged when shot by aliens or the player)
- Matei - powerups and scoreboard

## How to run

Install pygame:

`pip install pygame`

Run the game:

`python main.py`
